# Evaluacion-2-
Repositorio de geolocalizacion utilizable para calcular distancias desde cierto punto incluyendo tiempo y rutas 

## Ejecución
1. Definir la API key como variable de entorno:
   `export GRAPHHOPPER_API_KEY="su_clave"`
2. Ejecutar: `python3 graphhopper_parse-json_1.py`
3. Elegir perfil (auto, bicicleta, a pie), ingresar origen y destino.
4. Para terminar, escribir `s` o `salir`.
